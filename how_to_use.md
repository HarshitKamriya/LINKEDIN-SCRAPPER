# How to Use the LinkedIn Scraper Extension

## 1. Install the extension in your browser

### Chrome / Edge / Brave / Opera
1. Open your browser.
2. Go to chrome://extensions or edge://extensions.
3. Turn on "Developer mode" in the top-right corner.
4. Click "Load unpacked".
5. Select the folder containing this extension, which is the Scraper folder.
6. The extension should appear in your list of installed extensions.

### Firefox
1. Open Firefox.
2. Go to about:addons.
3. Click the gear icon and choose "Debug Add-ons".
4. Click "Load Temporary Add-on".
5. Select the manifest.json file inside the Scraper folder.
6. The extension will be installed temporarily for the current session.

## 2. Open LinkedIn Recruiter
1. Sign in to LinkedIn.
2. Open a LinkedIn Recruiter page.
3. Make sure you are on one of the supported pages:
   - Recruiter search results page: https://www.linkedin.com/recruiter/smartsearch*
   - Recruiter profile page: https://www.linkedin.com/recruiter/profile/*

## 3. Use the extension
1. Click the extension icon in the Chrome toolbar.
2. A popup should appear.
3. Click the button inside the popup to start the scrape.

## 4. What happens after you click
- If you are on a recruiter search results page, the extension will scrape the listed profiles.
- If you are on a recruiter profile page, the extension will scrape that single profile.
- The scraped data is converted into a table and copied to your clipboard.

## 5. Paste the extracted data
1. Open any spreadsheet, document, or text editor.
2. Paste the content.
3. The data will appear as a table-like HTML structure, which can be copied into a spreadsheet or reformatted as needed.

## 6. Notes
- The extension works only on LinkedIn Recruiter pages.
- Some profiles may require unlocking before the extension can read them.
- If a profile is locked, the extension may show a status message asking you to unlock it first.

## 7. Troubleshooting
- If nothing happens, confirm that you are on a supported LinkedIn Recruiter page.
- If the extension does not scrape correctly, refresh the page and try again.
- Make sure Developer mode is enabled and the extension is loaded correctly.
